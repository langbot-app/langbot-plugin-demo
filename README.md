# LangBot Plugin Demo

This repository contains a collection of demo plugins for LangBot. You can refer to specific plugin's README for more details.

- [RunnerDemo](RunnerDemo/README.md) — Two explicit EBA event processors with typed handlers, action traces, progress logs, failure handling, and 12 runnable scenarios. [简体中文](RunnerDemo/README.zh-CN.md)

For more information about LangBot Plugin, please refer to [LangBot Plugin Documentation](https://langbot.app/docs/zh/plugin/plugin-intro.html).
